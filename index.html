Stonkfly-inspired model ideas

The Stonkfly project uses a much larger retained MaleCNS graph and wiring-constrained spiking dynamics. Its native implementation needs Python/C++ and several GB of data, so it cannot be copied directly into GitHub Pages. This browser game instead keeps the same useful separation: sensory input → spiking network → fixed population readout → body behavior.
